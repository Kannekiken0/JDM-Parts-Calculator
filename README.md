# 🚗 JDM Parts Price & Discount Calculator

Консольное приложение на C++ для расчёта стоимости автозапчастей с поддержкой конвертации валют (USD -> JPY), автоматической системы скидок и формирования итогового чека.

---

## 🛠 Особенности и используемые технологии
* **Структуры и инкапсуляция:** Использование `struct Part` для объединения данных о детали (название, цена, количество)[cite: 7].
* **Контейнеры STL:** Управление списком покупок с помощью `std::vector`[cite: 7, 8].
* **Передача по ссылке (`const reference`):** Оптимизация работы с памятью и избежание лишнего копирования данных[cite: 8].
* **Логика скидок:** Автоматический пересчёт стоимости в иены (JPY) и применение скидочных порогов[cite: 7].
